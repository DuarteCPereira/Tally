Two to four mutually exclusive options in one group.

The group is `surface` with `radius-md` and `space-1` inside padding. The selected option sits on `surface-high` with `text-primary`; the others use `text-secondary`. Labels use `label`. Use it for a setting with a few fixed choices, such as System, Light and Dark.

**Planned Compose API**: `DuiSegmentedControl(options: List<String>, selectedIndex, onSelect, modifier)`.
