A section title in the `title` style with an optional text action on the right.

Use it to introduce a list or chart. The action uses `label` in `accent` and names the destination ("See all"). Leave `space-5` above and `space-2` below. Do not add icons or dividers; the whitespace is the separation.

**Planned Compose API**: `DuiSectionHeader(title, actionText = null, onAction = {})`.
