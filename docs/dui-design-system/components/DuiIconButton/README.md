A round, icon-only button with a `space-7` touch target.

It is transparent by default, or `surface` with `filled = true`. The icon is `text-primary`, or `text-disabled` when the button is disabled. It always needs a content description, because the icon is the only content.

**Planned Compose API**: `DuiIconButton(icon, contentDescription, onClick, modifier, enabled = true, filled = false)`.
