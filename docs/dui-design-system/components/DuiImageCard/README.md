A photo shown in a 16:9 card with `radius-lg`, cropped to fit.

With no photo it shows a flat `surface` block with an optional icon in `text-secondary`. There is no gradient, no overlay and no text on top of the image, so the card needs no extra colour tokens.

**Planned Compose API**: `DuiImageCard(image: ImageBitmap?, contentDescription, modifier, placeholderIcon = null)`. The app loads the image.
